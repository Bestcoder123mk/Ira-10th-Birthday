# Ira's 10th Birthday Anthem

A celebratory birthday web app with synchronized song lyrics, an audio-reactive
visualizer, and a tribute for Shrestha (Ira)'s 10th birthday.

## Run locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   `npm install`
2. Run the dev server:
   `npm run dev`

## Build for production

`npm run build` outputs a static site to `dist/`, ready to deploy anywhere
(Vercel, Netlify, etc.) with no environment variables required.
